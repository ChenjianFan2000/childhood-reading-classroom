# 《童年》公开课课件

用于《童年》课堂教学与投影展示的 40 幕交互式 HTML 课件，附与动画同步的教师逐字稿。

## 使用方法

在仓库页面点击 **Code → Download ZIP**，下载并解压后，使用浏览器直接打开 `index.html` 即可离线授课。也可以单独下载 `index.html`。图片、字体和课堂讲稿已内嵌在课件中。

| 操作 | 按键 |
| --- | --- |
| 下一幕 | →、空格或 PageDown |
| 上一幕 | ← 或 PageUp |
| 进入或退出全屏 | F；若浏览器不支持，可使用 F11 |
| 打开目录 | M |
| 查看教师讲稿 | N |
| 重播当前幕 | R |
| 开始或暂停计时 | T |
| 关闭面板 | Esc |

每一幕均由教师手动推进。将鼠标移到屏幕下方，也可使用控制栏。
