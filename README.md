# 《童年》公开课课件

面向六年级课堂投影的 40 幕交互课件，配有 40 分钟教师逐字稿。手绘画本中的小路、书桌、窗与纸面通过镜头移动相连，阅读材料在画面中央的留白处停稳。课堂保留初判、证据并读、三关阅读卡修复、小组探究与退出卡。

## 画面预览

![手绘画本封面：留白标题与校园小路](docs/preview-cover.jpg)

![阅读页面：双栏原文、纸面留白与页角手绘细节](docs/preview-reading.jpg)

开场的小路上，孩子会依次遇见伙伴、追球的同学和树荫。场景之间通过平移、轻推与景深变化相连；长段文字进入留白后停稳，细节动画结束后保持最后画面。

## 下载与离线使用

1. 在仓库页面选择 **Code → Download ZIP**，下载整个项目。
2. **完整解压**，保留 `index.html` 与 `assets`、`styles`、`scripts` 文件夹的相对位置。
3. 用浏览器打开解压后的 `index.html`，即可开始授课。

无需构建、安装依赖或启动服务器。插画、原画、真实资料照片、中文字体与课堂数据都随项目提供，可完全离线使用。素材已拆为独立文件并压缩；**仅下载 `index.html` 无法完整播放**。

课前请在实际投影设备上检查文字大小，并离线试播开场、长段原文、现实资料与结尾。

## 课堂操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 下一幕 | →、空格或 PageDown |
| 全屏时下一幕 | 在无交互控件处单击左键，或单击右键 |
| 上一幕 | ← 或 PageUp |
| 进入或退出全屏 | F，或控制栏全屏按钮 |
| 打开目录 | M |
| 查看教师讲稿 | N |
| 重播当前幕 | R |
| 开始或暂停计时 | T |
| 关闭面板 | Esc |

全屏中的空白左键与右键效果相同，都推进下一幕。按钮、关键词划线、可编辑区域、选中文字和已打开的面板保留各自操作，不触发空白点击推进。普通窗口模式下，空白处点击不会切换场景。将鼠标移到屏幕下方，可显示控制栏；文字输入完成后也可通过控制栏推进。

浏览器不支持页面全屏时会进入专注模式，点击规则相同，可再按 F11 隐藏浏览器边框。

每一幕都由教师手动推进。动画结束后停住，倒计时归零只作提醒，不自动切走阅读材料。两分钟并读、五分钟讨论与九十秒退出卡保留完整时间。

点击原文关键词可划线，再点一次可取消；断箭头关卡的两条箭头可分别断开与恢复。修订句、理由和小组主张由教师记录课堂中的实际表达，并保存在当前浏览器。目录中可清空本次课堂记录。

目录中另有“投影增强”与“简静动画”。声音默认关闭。教师讲稿和资料来源仅在教师面板显示，学生主画面保持清晰。

## 教师讲稿

[下载教师逐字稿（Word）](teacher_script.docx)

逐字稿与网页的 40 幕逐一对应；“画面与操作”已同步为镜头移动、纸面留白和新的细节动画，教学话语、原文证据与课堂时间保持原有安排。

## 项目结构

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` | 课件入口 |
| `assets/` | 本地插画、照片、字体与字体许可 |
| `styles/` | 画面布局、纸张效果与动画样式 |
| `scripts/lesson-data.js` | 场景顺序、阅读材料、教师讲稿与资料来源 |
| `scripts/scenery.js` | 场景细节与手绘物件 |
| `scripts/app.js` | 镜头切换、课堂互动、计时和全屏操作 |
| `teacher_script.docx` | 便于备课和打印的教师逐字稿 |

## 开发验证

维护代码时，可在项目根目录运行以下命令，无需安装依赖：

```bash
node --test tests/*.test.cjs
node --check scripts/app.js
node --check scripts/scenery.js
```

这些检查用于验证交互逻辑与脚本语法。发布前仍应在实际浏览器中检查镜头衔接、文字留白、长段落显示、离线加载，以及全屏点击和按钮操作。
