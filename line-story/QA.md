## 视觉复核与修正

人工查看了1366×768与1024×768的两栏并读、窗边长文、第二关、安妮原文、小组讨论，以及保护问答、作者改变、最终回望／支撑／日常的关键画面。

本轮实际发现并修正了以下问题：

- 安妮提问文字与窗框相交：为非阅读标题安排独立的清纸区域，问题仍在愿望停住后出现。
- 终场第三只手超出下边界、镜头跨场景飞行：重新安排局部镜头与支撑位置，保留同一主线连接。
- 1366×768下操作条遮住计时器下沿：抬高横屏计时位置，并加入矩形边界检查。
- Word中个别节拍的画面或停留说明被拆到下一页：用文档原生段落保持替代字符数估算分页，重新渲染确认。

教师台重开与最终延迟测试中另发现两处测试自身的等待问题，分别改为等待学生页确认断开，以及先完成被测试暂停的动作再进入下一拍；没有为适配测试改变课堂推进规则。

## 可复现命令

在 `line-story` 目录运行：

```bash
node tests/content.test.cjs
node tests/browser.test.cjs --out browser-report --screenshots
```

浏览器回归需要Node.js、Playwright和Chromium，可加 `--browser /path/to/chrome` 指定可执行文件。Python浏览器测试入口是同一程序的转发器。

文稿与清单重建：

```bash
python tools/build_script.py
python tools/build_manifest.py
```

Word重建需要python-docx与lxml；重建后应重新渲染检查。清单在内容和文稿定稿后生成，包含各发布文件的字节数与SHA-256。

## 验证边界

上述验证没有替代真实班级的40分钟试教，也没有遍历所有浏览器、替代字体、投影设备和翻页笔。情感效果仍需要学生阅读、发言与教师停顿共同完成。实际授课前，应使用现场设备走过长文、原画、保护问答、独立教师台和最后45秒；双窗口使用系统的扩展显示。
