# 发布验证

## 内容与同步

54个不重复的教学节拍（含课前封面），主体时间相加为2400秒。并读120秒、讨论300秒、退出卡90秒。教师逐字稿由同一份课堂数据生成，包含全部节拍ID及逐字话语，附数据SHA-256；Word与网页不分别维护两套内容。

三份真实素材与原仓库的Git blob一致；其余画面来自SVG。独立发布目录无字体二进制文件，无输入框、可编辑区域、外部脚本、分析服务或麦克风请求。

## 本地复核

在独立Chromium 144中完成54个节拍的正向推进和53次返回，检查原文、三份素材、辅助面板、关键词标记、箭头、结束不循环、全屏点击及计时。检查1600×900主画面，以及1366×768、1280×960的重点页面；390×844竖屏无横向溢出，长文可纵向滚动。

本地执行环境不开放file://及localhost导航，因此本地复核采用“原文件内容内联”的隔离渲染，未更改浏览器安全策略。该步骤不冒充实际文件路径加载；发布工作流另以原始目录和file://执行完整回归及离线加载检查。

Word已转换并检查27页排版。原始两份Word、旧40幕课件的材料和新版54节拍进行了内容对应复核。两篇新闻保留历史报道日期，画作不当作小说事件照片，瓦尔瓦拉图片不改造成烛光照片。

## 可复现检查

```bash
node --test tests/content.test.cjs
python tests/browser_test.py --out browser-report --screenshots --motion
```

浏览器回归需Python Playwright与其Chromium。默认命令使用实际file://文件：先逐页检查静态终态和交互，再以完整动画逐步走完全部53次“下一页”；另用新建的离线上下文加载三张真实图片。计时边界通过加速时钟验证，不需要让每次开发检查等待40分钟。

文稿重建：`python tools/build_script.py`（需python-docx、lxml）。重建后须重新渲染和检查Word版式。发布清单 `manifest.json` 用SHA-256校验文件字节。

## 验证边界

浏览器回归不是40分钟真实班级试教，也不证明所有设备、浏览器和翻页笔表现完全相同。上课前仍需用实际投影设备检查字体替代、原文字号、全屏与翻页笔。情感效果需要教师语速、停顿和学生实际发言共同完成。
