# 发布验证

验证日期：2026年10月24日。对应 `line-story 2.0`。本页记录本轮实际执行结果，不沿用旧版的浏览器或页面数量结论。

## 内容与同源文稿

- 57个不重复节拍，15个连续授课节点；主体时间合计2400秒。
- 并读120秒、小组讨论300秒、独立书写90秒；窗边100秒阅读与15秒静看；两张照片各38秒。
- 保护之后的问答按顺序揭示；学生判断在默认断线之前；断线后原文仍保留。
- 安妮三处短引来自不同篇章，作为独立块保留；背景整理与原文区分，教师资料分别记载出处与日期。
- 最后45秒的前两幕不说旁白，最后只保留一句收束。
- Word与Markdown由同一份课堂数据生成，文稿数据SHA-256与网页完全一致。Word最终29页，已重新渲染并逐页检查。
- 三份真实素材的SHA-256与原版完全相同；没有新增位图、网络字体或教师输入框。

## 浏览器实际运行

在独立 **Chromium 156.0.8078.47** 中，以原始目录的 **file://** 地址实际加载，并使用离线上下文。没有内联替代HTML、替换图片路径或使用用户浏览器会话。

完整浏览器回归通过15项检查，覆盖：

1. 全部57个节拍的正向推进、56次返回。
2. 全部56个有动画的前进转换；动作期间首次推进只完成动作，不跳过教学节拍。
3. 同一主线DOM贯穿课程，路径形变、暂停、继续与完成均可控。
4. 第二关断线前后保留同一原文和箭头DOM；返回恢复待判断状态。
5. 原文划词在前后导航和刷新后保留。
6. 保护后半问答不提前泄露；回读弹层不包含教师提示。
7. 1600×900、1366×768、1280×960、1024×768与390×844，共109次文本边界检查；竖屏长文可以纵向阅读，没有水平溢出。
8. 三张本地图片在离线上下文中正常加载；使用contain完整显示，指定收回节拍后移除。
9. 普通和全屏状态默认空白点击、右键不推进。
10. R保留计时，Shift+R单独重置；T暂停、B暂隐、计时到零和刷新均维持正确的活动状态。
11. 独立教师台显示15节点并远程操作；学生页刷新后立即按下一步可正确重连；关闭教师台后可以重开。
12. 不相关窗口或错误会话的控制消息被拒绝。
13. A暂停期间局部镜头不再移动；暂隐恢复后维持原先的暂停意图。
14. 最终结语延迟8秒出现，动画完成后静止，没有自动跳转或循环。
15. 学生窗口与教师台均无未捕获JavaScript错误，无HTTP(S)网络请求。

另对全部57个节拍逐一比较世界层的“完成动作”与“直接恢复终态”：可见组、变换、透明度和路径一致，没有残余运行或暂停的世界动画。

人工复核关键截图：两栏并读、窗边长文与坐姿、安妮三短引、推论断开、保护与代价、问答、两张纪实照片、最终回望／支撑／普通日常及教师台。修正了保护代价痕迹的位置、窗边坐姿，以及学生页刷新后教师台首个操作可能丢失的竞态。

最终视觉复核还检查了两项定向修正：阅读区的清纸底使窗框等线条不再穿过正文；教师台操作栏置顶并保持可见，鼠标推进后当前旁白会回到视野中，同一节拍的计时或暂停操作不打断教师滚动阅读。上述修正不改变原文字号、课程数据、动作或时长。

## 可复现命令

```bash
node --test tests/content.test.cjs
node tests/browser.test.cjs --out browser-report --screenshots
```

浏览器回归需要Node.js、Playwright和Chromium。可加 `--browser /path/to/chrome` 指定可执行文件。原Python入口保留为同一程序的转发器；不再保留一套与新控制行为不一致的旧测试。

文稿与清单重建：

```bash
python tools/build_script.py
python tools/build_manifest.py
```

Word重建需要python-docx与lxml，重建后应重新渲染检查。发布清单包含每个文件的字节数和SHA-256。内容测试核对节拍、时间、原文、来源、三份素材、同源文稿、入口依赖及清单。

## 验证边界

上述检查不是一次真实班级的40分钟试教，也不证明所有浏览器、字体替代、投影和翻页笔都完全相同。实际授课前请确认中文字体、全屏、长文、独立教师台和最后45秒。双窗口必须配合系统的扩展显示；镜像显示无法隐藏教师窗口。情感效果仍需要教师的语速、停顿与学生的阅读和发言共同完成。
