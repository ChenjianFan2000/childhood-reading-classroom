# 《童年》线条叙事版

**独立版本入口：`line-story/index.html`。** 原仓库根目录的旧课件未被替换。

40分钟，54个教学节拍（含课前封面），11个相连的矢量场景。线条分别承担人与人的联系、生活处境的限制、需要检验的推论。页面不设输入框；学生在阅读本完成自己的表达。

## 开始授课

下载并完整解压仓库，打开本文件同目录下的 **index.html**。也可以只保留完整的 `line-story` 文件夹。不要只下载HTML：三张图片、样式和脚本需要保持相对目录。

课件没有后端、安装步骤、外部脚本、网络字体、自动播放音乐或语音识别。中文字体优先使用设备上的思源宋体／思源黑体，其次回退到宋体、微软雅黑或系统字体。实际投影设备的字体和字号应在课前检查。

## 正常课堂只用“下一页”

| 操作 | 按键 |
| --- | --- |
| 下一页（完整默认主线） | →、空格、PageDown，或底部按钮 |
| 上一页 | ←、PageUp |
| 全屏 | F |
| 目录／教师提示 | M／N |
| 当前计时暂停、继续 | T |
| 重播本节拍、重置当前计时 | R |
| 关闭辅助面板 | Esc |

全屏状态下，在非按钮、非划词、非选中文字处左键单击，或右键，也可推进。普通窗口中空白点击不推进。辅助面板打开时，先关闭面板再继续主线。底部操作栏在鼠标靠近时显示；阅读时可隐藏。

**每个节拍都等待教师推进。** 倒计时结束不会跳走。三份真实材料在指定节拍展开，下一次相应推进后收回；“随旁白”指教师按键同步，并非麦克风监听。

两分钟并读、五分钟小组讨论、九十秒退出卡保留独立计时。活动提示、原文隐去与回看、修订笔迹、断开推论、安妮的愿望、资料收回、最后收束全部在默认路径内。阅读本记录不被预设答案替代。

按需操作只用于回应学生：原文划词、两条箭头的检验、讨论页证据放大。目录提供“投影增强”“简静动画”。**教师提示显示在当前屏幕，投影授课时须留意学生也能看到。**

## 视觉与阅读主线

普通日常 → 伤害与温暖的不同作用 → 外祖父的经历与解释 → 补回代价、检验推论、准确赞美 → 保护后仍可能有“下一次” → 安妮得到帮助但愿望仍受限 → 两份文本支撑小组主张 → 作者回望与现实儿童 → 独立书写 → 共同承担，回到普通的一天。

只有列宾原画、亚门与父亲的纪实照片、瓦尔瓦拉与母亲的纪实照片使用位图，其余场景为原创SVG。照片不作生成式修改，不把历史报道说成即时近况，不为真实儿童虚构获救结局。阅读材料居中、动画结束即静止；非连续摘录用留白分段，出处保留在教师资料中。

## 文件结构

```
line-story/
  index.html
  scripts/lesson-data.js    # 唯一内容源
  scripts/world.js          # 持续存在的SVG线条世界
  scripts/app.js            # 教师控制、计时、阅读支线
  styles/story.css
  assets/                  # 指定的3张本地真实素材
  teacher_script.docx
  teacher_script.md
  SOURCES.md
  QA.md
  manifest.json            # 发布文件校验值
  tests/browser_test.py
  tests/content.test.cjs
  tools/build_script.py
```

课堂本身无需依赖。开发检查可运行 `node --test tests/content.test.cjs`。浏览器回归使用Python Playwright与Chromium；文稿重建使用python-docx。完整浏览器检查命令见QA.md。

本课件的浏览器回归不代替实际课堂试教。正式上课前，请在教室投影、使用的浏览器与翻页笔上走一遍原画、双栏原文、三关转折、讨论计时和最后40秒。
