# 《童年》线条叙事版

**授课入口：[index.html](index.html)。教师台由学生窗口按 P 或 N 打开。**

40分钟，15个授课节点，57个内部节拍（含课前封面），11个持久的矢量场景。日常的路、书页、人物之间的联系、被检验的推论、保护与共同支撑，由一条持续演化的线连接。学生在阅读本上表达，网页不需要输入答案。

当前版本为 **2.1**。逐段课程审查与实施方法见 [审查与修改记录](REVIEW-DECISIONS.md)，实测范围见 [验证说明](QA.md)。

## 本次优化的重点

课程保持“辨认影响 → 检验赞美的理由 → 论证幸福童年的条件”这条问题链。没有增加节拍，也没有挤占两分钟并读、五分钟小组讨论和九十秒独立书写。

- 首轮阅读先让学生自己选证据。外祖父一段先读受苦经历，再揭示他对打孩子的辩护；理解与质疑分别发生。
- 第二关同时检验两条推论。收束时保留两个经历事实，两条未经证据支持的因果箭头都断开；网页箭头与线条图同步。返回或刷新保留教师按课堂发言标记的选择。
- 安妮的帮助物品真实抵达，愿望随后向外延伸，在独立危险边界前停住，再出现问题。帮助不会被抹去，少女也不会被动画带到屋外。
- 作者段先听学生读出原文依据，再由教师推进“改变”的动作。有害分支独立退离，书页另起一条暖线，避免画成苦难滋养了善良。
- 两张纪实照片用来检验小组主张：怎样让一次帮助成为每天可依靠的生活条件。结尾先认出手、窗、学校与灯，再让不同支撑接稳；最后回到开场日常，不再穿行全部场景。

## 打开与投影

完整下载并解压仓库，双击本目录的 **index.html**。也可以单独保留完整的 `line-story` 文件夹。三张图片、脚本和样式须保持目录关系，不能只下载HTML。

网页使用本地文件，不需要后端、联网脚本、网络字体、安装依赖或声音设备。中文字体优先使用思源宋体／思源黑体，再回退到宋体、微软雅黑、苹方或系统字体。

双屏授课时，系统选择**扩展显示**，将学生窗口放到投影屏，教师台留在电脑屏。镜像显示无法隐藏教师台。若浏览器拦截弹窗，请允许本页弹出窗口，再按 P。教师台关闭后再次按 P，会回到当前节拍。

## 正常授课只用下一步

每个节拍都等待教师推进。活动计时结束停在原地。三份真实材料由教师推进打开和收回；没有麦克风监听、语音识别或整课自动播放。

| 操作 | 按键 |
| --- | --- |
| 下一步 | →、空格、PageDown，或底部按钮 |
| 上一步，恢复上一画面的终态 | ←、PageUp |
| 全屏 | F |
| 15节点目录 | M |
| 独立教师台 | P 或 N |
| 暂停／继续活动计时 | T |
| 只重播当前动作，保留活动计时 | R |
| 重新开始本次活动计时 | Shift + R |
| 暂停／继续画面动作 | A |
| 暂隐学生屏，同时暂停计时与动作 | B；B或Esc恢复 |
| 前一个／后一个授课节点 | [ ／ ] |
| 关闭回读或目录 | Esc |

**动画尚未完成时，第一次推进只完成当前动作；再次推进才进入下一节拍。** 返回和目录跳转直接恢复目标终态。默认空白点击和右键都不翻页；只有在教师台显式开启后，全屏右键才会推进。

暂隐恢复时保留原先的暂停意图：原本暂停的计时不会意外开始。刷新会在当前会话中保留进度、划词、判断箭头、计时和显示设置。教师台会重新连接学生窗口。“重新开始”清除本课的进度与记录；关闭会话后的存储行为由浏览器决定。

## 阅读与课堂节奏

主线包含外祖母的完整长段、窗边与萨沙共同沉默的长段、保护的动作与后半问答。安妮部分补回旧教师稿中三处有来源的独立短引与背景，不把它们拼成一篇日记。

通读时文字居中，世界退至下缘；细读时原句连接人物局部；回看时可返回两份证据。推论断开前后保留原文，三轮游戏留下修订痕迹。象征笔迹只表示表达或修改已经发生，不冒充学生的实际回答。

保留120秒并读、300秒小组讨论、90秒独立书写。窗边主线有100秒阅读、15秒静看；亚门和瓦尔瓦拉的照片各留38秒、各用8秒收回。最后45秒先让世界与共同支撑完成，只有最终一句旁白；结语在最后画面展开8秒后出现，随后静止。

教师台可看当前逐字话语、停留安排、按需承接、下一画面内容、活动计时、课堂实际用时与40分钟余量。学生主窗口不再展开教师讲稿，证据弹层也不含教师专用提示。

## 开发与复核

课堂运行无需安装依赖。维护检查可用：

```bash
node --test tests/content.test.cjs
node tests/browser.test.cjs --out browser-report --screenshots
python tools/build_script.py
python tools/build_manifest.py
```

浏览器测试需要Node.js、Playwright和Chromium；可用 `--browser /path/to/chrome` 指定浏览器。原有 `python tests/browser_test.py` 入口会转交同一份Node回归程序。Word重建需要python-docx和lxml。文件清单在内容与文稿最终确认后生成，校验每个发布文件的字节数与SHA-256。

测试使用实际file://目录和离线上下文，检查所有节拍、返回、原文保留、教师台、计时、动作控制和常见屏幕尺寸。正式上课前，请使用实际投影与翻页笔走过长文、原画、保护问答、双窗口以及最后45秒。
