本轮可用输入是已保存的 2.0 Markdown 教师逐字稿（15个授课节点、57个内部节拍）和仓库 1.0 的完整源码。此前会话中的 2.0 前端工作目录未保留，因此本轮的前端是依据这些材料恢复实现，而非声称找回了丢失的源码。

## 发布原则

- 使用 GitHub 插件的真实写入操作；创建分支不等于已经发布。
- 在目标分支回读文件、校验提交和完整发布目录。
- 只报告实际执行的检查，不把截图、文稿或旧版压缩包当成新版源码。
- 不开启 GitHub Pages，不改动仓库根目录的旧课件入口。
